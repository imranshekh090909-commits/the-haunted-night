# THE HAUNTED NIGHT

Realistic-ish 3D multiplayer horror survival for Android, 1-4 players with room-code matchmaking.

This repository is the Unity 2022.3 LTS project scaffold: gameplay, networking, AI, UI and optimization systems are written. Art, audio and level geometry are plug-in work - see `docs/ASSETS_AND_SIZE_BUDGET.md`.

No .apk is committed here. An APK can only be produced by Unity's Android build pipeline on your machine or a CI runner - see `docs/BUILD_APK.md`.
